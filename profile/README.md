## 🚀 Featured Projects

Here is a look at what we've been building:

### 🤖 [LazyDev](https://github.com/FutureMindsDev/lazydev-server) · *AI-Native Autonomous Issue Resolver*
- **[lazydev-server](https://github.com/FutureMindsDev/lazydev-server)** & **[lazydev-client](https://github.com/FutureMindsDev/lazydev-client)**
- An autonomous CI engineering partner powered by a 5-stage **LangGraph** multi-agent pipeline. It monitors repository issues, reproduces bugs in isolated Docker sandboxes, formulates plans, writes verified patches, and opens clean pull requests automatically.
- **Tech**: NestJS, TypeScript, LangGraph, Ollama / LLM APIs, Docker sandboxes, Redis, PostgreSQL, Qdrant.

### 👗 [fitAura](https://github.com/FutureMindsDev/fitAura) · *AI-Powered Virtual Fitting Room*
- A multimodal try-on experience leveraging Google's **Gemini 2.5 Flash Image** model. Seamlessly blends user portraits with fashion apparel to generate photorealistic try-on results in seconds.
- Built for the Kaggle Gemini Flash Image Challenge to transform fashion e-commerce and creative styling.
- **Tech**: Python, Google GenAI (Gemini API), Pillow.

### 🎙️ [audio-transcriber (whisper-cli)](https://github.com/FutureMindsDev/audio-transcriber) · *Lightning-Fast Private Speech-to-Text*
- Transcribe hours of audio in minutes with **100% privacy** — all computations happen locally without data leaving your device.
- Powered by `faster-whisper` for optimized CTranslate2 inference.
- **Tech**: Python, faster-whisper, CTranslate2.

### 💡 [TechSuggest](https://github.com/FutureMindsDev/TechSuggest) · *AI Messenger Bot for Gadget Recommendations*
- An intelligent conversational Messenger assistant providing swift, tailored gadget comparisons and hardware purchase recommendations.
- **Tech**: Node.js, Meta Messenger API, LLM integration.

### 📚 [aws-developer-questions](https://github.com/FutureMindsDev/aws-developer-questions) · *AWS Certification Training Platform*
- Interactive study companion and exam-practice platform for developers mastering the AWS Certified Developer Associate certification.
- **Tech**: Next.js, React, Tailwind CSS, TypeScript.
